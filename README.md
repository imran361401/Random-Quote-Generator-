# Random Quote Generator

**Автор:** [Маргушев Имран]  
**Описание:** Программа на Python для генерации случайных вдохновляющих цитат. Позволяет просматривать историю запросов, фильтровать её и автоматически сохраняет данные в JSON.

### Функционал:
- Генерация случайной цитаты из базы.
- Сохранение истории просмотров.
- Фильтрация истории по автору или категории.
- Автоматическая загрузка истории при запуске.

### Как запустить:
1. Установите Python 3.x.
2. Запустите файл: `python main.py`.
